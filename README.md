<p align="center">タスクバーの上でマウスホイールを回すだけで、音量を変えられる Windows 用の常駐アプリです。</p>

## できること

- タスクバーの上でホイールを回すと、既定の再生デバイスの音量が変わります。1 段あたりの変化量は 1〜20% から選べます (初期値は 2%)。
- タスクバーの上でホイールを押し込む (中クリックする) と、ミュートのオンとオフが切り替わります。
- 音量を変えると、操作したモニターの隅に音量とデバイス名を少しのあいだ表示します (OSD)。
- トレイアイコンの波の本数で、今の音量がおおまかにわかります。アイコンにカーソルを合わせると、音量とデバイス名を表示します。
- Volm が処理したタスクバーの上のホイールと中クリックは、ほかのアプリには渡しません。タスクバー以外の場所での操作には、Volm は何もしません。

次の機能は開発中です。設計は [docs/DESIGN.md](docs/DESIGN.md) にあります。

- Ctrl+ホイールでモニターの明るさを変える。内蔵ディスプレイと DDC/CI に対応した外部モニターは明るさそのものを変え、どちらにも対応しないモニターは画面に半透明の黒を重ねて暗くする
- タスクバーのアプリのボタンの上で Alt+ホイールを回し、そのアプリの音量だけを変える
- トレイのメニューから出力デバイスを切り替える
- ホットキー (Win+↑/↓ での音量など) と、メディアキーの送信
- インストーラーと、設定画面からのアップデート

## 動作環境

- Windows 11 (x64)。Windows 10 (x64) にも対応する予定ですが、まだ動作を確かめていません。
- 管理者権限は要りません。

## インストール

まだリリースはありません。今は、ソースからビルドして使います。手順は [CONTRIBUTING.md](CONTRIBUTING.md) の「ビルドと実行」を見てください。

## 使い方

Volm を起動すると、通知領域にアイコンが表示されます。Windows 11 では、新しいアイコンは最初「隠れているインジケーター」(タスクバーの `^`) の中に入ります。いつも見えるようにしたいときは、アイコンをタスクバーまでドラッグしてください。

| 操作 | 動作 |
|---|---|
| タスクバーの上でホイール | 音量を上げ下げする |
| タスクバーの上で中クリック | ミュートを切り替える |
| トレイアイコンを左クリック | 設定画面を開く |
| トレイアイコンを右クリック | メニュー (ミュート、設定、終了) を開く |

Volm を起動したまま、もう一度 Volm を起動しても、設定画面が開くだけです。2 つ目の Volm は常駐しません。

### 設定

設定画面では、次の項目を変えられます。変更はすぐに反映され、保存ボタンはありません。

| ページ | 項目 |
|---|---|
| 一般 | Windows の起動時に起動する、音量を上げたらミュートを解除する |
| 音量 | ホイール 1 段で変わる音量、中クリックでミュートを切り替える |
| OSD (画面表示) | OSD を表示する、表示する位置、表示する時間 |
| 情報 | バージョン、ライセンス、使っているライブラリ |

左下の「初期値に戻す」を押すと、確認のあとですべての設定が初期値に戻ります。

設定は `%APPDATA%\Volm\config.json` に、ログは `%APPDATA%\Volm\volm.log` に保存されます。設定ファイルが壊れて読めないときは、そのファイルを `config.json.bak` に移し、初期値で起動します。
