<p align="center">タスクバーの上でマウスホイールを回すだけで、音量とモニターの明るさを変えられる Windows 用の常駐アプリです。</p>

## できること

- タスクバーの上でホイールを回すと、既定の再生デバイスの音量が変わります。1 段あたりの変化量は 1〜20% から選べます (初期値は 2%)。Shift を押しながら回すと 1% ずつ変わります。設定で「速く回すと大きく変える」をオンにすると、速く回したときの変化量が最大 4 倍になります (初期値はオフ)。
- タスクバーの上でホイールを押し込む (中クリックする) と、ミュートのオンとオフが切り替わります。
- 音量を変えると、操作したモニターの隅に音量とデバイス名を少しのあいだ表示します (OSD)。
- Ctrl を押しながらタスクバーの上でホイールを回すと、カーソルのあるモニターの明るさが変わります。Ctrl と Shift を押しながら回すと、すべてのモニターの明るさが同じだけ変わります。
- 明るさの変え方は、モニターごとに自動で選びます。内蔵ディスプレイは WMI で、DDC/CI に応える外部モニターは DDC/CI で明るさそのものを変えます。どちらにも応えないモニターは、画面に半透明の黒を重ねて暗くします。
- タスクバーのアプリのボタンの上で Alt を押しながらホイールを回すと、そのアプリの音量だけが変わります。開いているウィンドウのタイトルバー (ブラウザーならタブが並ぶ部分) の上でも同じように変えられます。ブラウザーのように、別のプロセスで音を鳴らすアプリにも効きます。
- ホットキーで、音量、ミュート、明るさ、曲の再生と一時停止、次の曲、前の曲、出力デバイスの順送り、マイクの音量とミュートを操作できます。初期値では Win+↑/↓ で音量、Ctrl+Shift+Q で再生/一時停止、Ctrl+Shift+E で次の曲です。どのアプリが前面にあっても使えます。
- トレイのメニューから、出力デバイス (既定の再生デバイス) と入力デバイス (既定の録音デバイス) を切り替えられます。マイクのミュートも切り替えられます。
- トレイアイコンに今の音量を数字で表示します。ミュート中は数字が薄くなります。アイコンにカーソルを合わせると、音量とデバイス名を表示します。
- 設定で「全画面のアプリの前では止める」をオンにすると、ゲームや動画を全画面で表示している間は、タスクバーのホイールをほかのアプリに渡し、OSD も表示しません。ホットキーは使えます。初期値はオフです。
- Volm が処理したホイールと中クリックは、ほかのアプリには渡しません。タスクバーの上と、ウィンドウのタイトルバーの上での Alt+ホイール以外の操作には、Volm は何もしません。


## 動作環境

| 項目 | 内容 |
|---|---|
| OS | Windows 11 (x64)。Windows 10 (x64) にも対応する予定ですが、まだ動作を確かめていません |
| 権限 | 管理者権限は要りません |
| 明るさの調整 | 内蔵ディスプレイ (WMI)、DDC/CI に対応した外部モニター。どちらにも対応しないモニターは、画面を暗く重ねる方法で暗くします |

## インストール

[Releases](https://github.com/otnc/Volm/releases) から `Volm-Setup-<バージョン>.exe` をダウンロードして実行します。管理者権限は要らず、`%LOCALAPPDATA%\Programs\Volm` に入ります。インストーラーにはコード署名がないため、初めて実行するときに Windows SmartScreen の警告が出ることがあります。そのときは「詳細情報」から「実行」を選んでください。

インストーラーを使わない場合は、`Volm-<バージョン>-windows-amd64.zip` を好きなフォルダーに展開して `Volm.exe` を実行します。ソースからビルドする手順は [CONTRIBUTING.md](CONTRIBUTING.md) の「ビルドと実行」にあります。

新しいバージョンは、設定画面の「更新」のページから確かめて入れられます。起動時にも 1 日に 1 回まで確かめ、新しいバージョンがあれば通知します。

## 使い方

Volm を起動すると、通知領域にアイコンが表示されます。Windows 11 では、新しいアイコンは最初「隠れているインジケーター」(タスクバーの `^`) の中に入ります。いつも見えるようにしたいときは、アイコンをタスクバーまでドラッグしてください。

| 操作 | 動作 |
|---|---|
| タスクバーの上でホイール | 音量を上げ下げする |
| タスクバーの上で Shift+ホイール | 音量を 1% ずつ上げ下げする |
| タスクバーの上で Ctrl+ホイール | カーソルのあるモニターの明るさを上げ下げする |
| タスクバーの上で Ctrl+Shift+ホイール | すべてのモニターの明るさを上げ下げする |
| タスクバーのアプリのボタンの上で Alt+ホイール | そのアプリの音量を上げ下げする |
| ウィンドウのタイトルバーやタブの上で Alt+ホイール | そのウィンドウのアプリの音量を上げ下げする |
| タスクバーの上で中クリック | ミュートを切り替える |
| トレイアイコンを左クリック | 設定画面を開く |
| トレイアイコンを右クリック | メニュー (ミュート、マイクをミュート、出力デバイス、入力デバイス、設定、終了) を開く |

Volm を起動したまま、もう一度 Volm を起動しても、設定画面が開くだけです。2 つ目の Volm は常駐しません。Volm の終了と再起動は、トレイのメニューのほか、設定画面の「一般」のページからもできます。

タスクバーのホイールでの音量や明るさの操作が要らないときは、設定画面の「音量」や「明るさ」のページで、それぞれオフにできます。オフにした操作は、ほかのアプリにそのまま渡ります。

### 設定

設定画面では、次の項目を変えられます。変更はすぐに反映され、保存ボタンはありません。

| ページ | 項目 |
|---|---|
| 一般 | Windows の起動時に起動する (初期値はオン)、音量を上げたらミュートを解除する、全画面のアプリの前では止める (初期値はオフ)、Volm の再起動と終了、アンインストール |
| 音量 | タスクバーのホイールで音量を変える、ホイール 1 段で変わる音量、速く回すと大きく変える (初期値はオフ)、中クリックでミュートを切り替える、Alt+ホイールでアプリごとの音量を変える、ウィンドウのタイトルバーでもアプリの音量を変える |
| 明るさ | タスクバーのホイールで明るさを変える、ホイール 1 段で変わる明るさ、暗く重ねるときの下限、モニターごとの方法 (自動、WMI、DDC/CI、画面を暗く重ねる、使わない) |
| 更新 | 今のバージョン、起動時に更新を確認する、プレリリースも対象にする、更新の確認とインストール |
| ホットキー | 操作ごとのキーの組み合わせ (2 つまで)。「追加」を押してからキーを押すと記録され、Esc で取り消せます。文字や矢印などのキーは Ctrl、Alt、Shift、Win のどれかと組み合わせます。F13〜F24、メディアキー、拡張キーボードやマクロパッドの専用キーは、それだけでも割り当てられます |
| OSD (画面表示) | OSD を表示する、表示する位置、表示する時間 |
| 情報 | バージョン、ライセンス、使っているライブラリ |

各項目の右端の丸い矢印のボタンを押すと、その項目だけが初期値に戻ります。今が初期値の項目では、このボタンは押せません。左下の「初期値に戻す」を押すと、確認のあとですべての設定が初期値に戻ります。

設定は `%APPDATA%\Volm\config.json` に、ログは `%APPDATA%\Volm\volm.log` に保存されます。設定ファイルが壊れて読めないときは、そのファイルを `config.json.bak` に移し、初期値で起動します。
